## Menjalankan

Buka `index.html` di browser. Tidak perlu server dan tidak perlu proses build.

### GitHub Pages

1. Push `index.html`, folder `css/`, folder `js/`, dan `README.md` ke repo, branch `main`. (Folder `assets/` lokal tidak perlu di-push; foto profil dimuat dari Vercel.)
2. Di repo, buka **Settings → Pages**.
3. Pada **Source**, pilih **"Deploy from a branch"**, branch `main`, folder `/` (root).
4. Simpan, lalu buka alamat `https://<nama-pengguna>.github.io/<nama-repo>/`.
